stoqr Android — Regressions-Report & Test-Leitfaden

Deine gemeldeten Beobachtungen (Test der Version v0.2.6), die jeweilige Ursache, der durchgefuehrte Fix und wie/wo zu testen ist. Stand: Phase 1 (Datenpfad) abgeschlossen; Phase 2 (UI/Design-System) folgt.

BEHOBEN in Phase 1 (Datenschicht)  ·  PHASE 2 UI/Usability, folgt  ·  Detaillierte technische Testfaelle: docs/test-manifest.html Bloecke G59 (Schreiboperationen), G56–G58.

Generell

PHASE 2 App-Logo & Drawer fehlen

Ursache
Die Schrift (Sora/Inter) wird per Remote-@import von Google Fonts geladen — offline im WebView tot, daher degradiert der „stoqr"-Schriftzug. Der Drawer selbst ist korrekt verdrahtet.
Fix
Phase 2: Schriften lokal buendeln (@font-face + WOFF2 in static/).
Test
Nach Phase-2-Build: Schriftzug „stoqr" in der gewohnten Schrift; Hamburger-Menue oeffnet den Drawer.

PHASE 2 Einheiten in Select-Feldern doppelt

Ursache
Keine Eindeutigkeit auf units.symbol; Seed-System-Einheiten und importierte/zugefuegte Haushalts-Einheiten mit gleichem Symbol koexistieren; getUnits merged ohne Dedupe.
Fix
Phase 2: Dedupe in getUnits (System bevorzugt) + Symbol-Kollisionsschutz beim Anlegen/Import.
Test
Nach Phase 2: in jedem Einheiten-Dropdown jedes Symbol nur EINMAL.

PHASE 2 Pruefungs-Pill „Pruefung nicht moeglich" / falsche Version

Ursache
Offline-Stub liefert reason:'offline' (nicht als benigne Meldung gemappt) und eine hart codierte Version 0.1.0.
Fix
Phase 2: offline-Meldung freundlich mappen; echte Build-Version anzeigen.
Test
Nach Phase 2: Pill zeigt aktuelle Version + neutralen Offline-Hinweis statt Fehler.

Einstellungen

PHASE 2 Scroll-Position bei Breadcrumb-Zurueck verloren

Ursache

Fix
Phase 2: snapshot/history.back() fuer Scroll-Erhalt.
Test
Nach Phase 2: Zurueck ueber Breadcrumb behaelt die Scroll-Position.

PHASE 2 „Sync in Vorbereitung"-Karte sieht wie Textwueste aus

Ursache

Fix
„Not found" ist BEHOBEN (routeApp settings/sync-Zweig, G59-4). Die Darstellung folgt in Phase 2 (globale Primitiven).
Test
Jetzt: Speichern der Sync-Karte wirft keinen „Not found" mehr. Nach Phase 2: Karte korrekt gestylt.

Test
Jetzt: Werksreset A/B/C mit korrekter Phrase fuehrt aus (Stufe C stellt Kategorien/Naehrwerte wieder her). Nach Phase 2: Modal-Buttons korrekt im Rahmen.

Sobald das naechste App-Release installiert ist, die mit BEHOBEN markierten Punkte durchgehen — alle Schreib-Aktionen sollten ohne SQL-Fehler speichern. Empfohlene Reihenfolge:

  1. Einstellungen → Danger-Zone → Werksreset Stufe C (frischer, konsistenter Stand).
  2. Raum + Lagerort + Fach anlegen.
  3. Kategorie (Haupt + Unter) + Kategorie-Zuordnungsregel anlegen.
  4. Artikel anlegen, Pfand setzen, Bestand korrigieren, Soll-/Mindestbestand, Markt-Zuordnung, Preis erfassen.
  5. MHD-Ampel + MHD-Toleranz je Kategorie speichern; Preis-Abruf-Schalter; Sync-Karte speichern.
  6. „Alles loeschen" auf einem Testartikel.
